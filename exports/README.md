# agriSense ML data export

Neon exports: 34 ML prediction records, 5 weather snapshots, and 0 stored training examples. Farmer email addresses are omitted from the prediction export.

The `synthetic_*_training.csv` files contain the generated examples used to train the current weather, crop, and yield models. They are synthetic examples, not recorded farm outcomes. The `training_data.csv` file is empty apart from its header because Neon currently has no stored labeled training rows.
